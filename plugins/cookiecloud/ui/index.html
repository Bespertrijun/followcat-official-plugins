CookieCloud 连接

CookieCloud 服务端的根地址（浏览器扩展里填的那个「服务器地址」；服务端设了 API_ROOT 路径前缀的，前缀也要带上）。别填 127.0.0.1 / localhost——插件出网会拦截本机回环地址；局域网地址（如 192.168.x.x）与 Tailscale 地址（100.64.0.0/10，如 100.101.102.103）可以。
插件只从服务端取密文，在 FollowCat 本地解密，密码不会发给 CookieCloud 服务端。两种加密方式（legacy / aes-128-cbc-fixed）都支持，自动按服务端记录识别。

同步哪些站

按每个 PT 站 RSS 链接的域名去 CookieCloud 里找 cookie，所以站点要先在 FollowCat 的 PT 站设置里配好 RSS。默认一个都不勾：勾上的站，其现有 Cookie 会被浏览器里的 cookie 覆盖（没变就不写）。API Key / passkey 鉴权的站不在此列。

自动同步

推荐 30 分钟。填 0 或留空 = 不自动同步（只在点「立即同步」时同步）。保存后立即按新间隔生效，第一次自动同步在满一个间隔之后。
CookieCloud 官方服务端有限流：同一 IP 15 分钟最多 100 次请求，间隔别设太小。
「立即同步」用的是已保存的设置。
