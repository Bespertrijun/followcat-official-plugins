按 RuleFlow 配置否决规格

每条 ruleflow 单独配置：启用开关控制是否参与否决；勾选要收的规格维度并填写期望值——库内副本须在所有已勾维度上等于配置值才算「已有」，未勾选的维度不参与判定；若库内副本解析不出已配维度，按「不符合」处理（宁多推不误杀）。启用但不勾任何维度 = 库里有该集任意副本即否决。
