按 RuleFlow 配置比对维度

每条 ruleflow 单独配置：启用开关控制是否参与去重；勾选要比对的维度并选择操作符—— 种子 tag 与库内副本须在所有已勾维度上都匹配才算「库里已有」并跳过下载。 未勾选的维度不参与判定。启用但不勾任何维度 = 不做去重（放行）。
